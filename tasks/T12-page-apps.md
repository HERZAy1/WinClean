# T12 页面二：软件占用分析

**前置**：T11

## 目标
展示每个软件的占用，并以"本体 / 必要缓存 / 非必要缓存"三段呈现，入口衔接一键清理（清理逻辑在 T13）。

## 要做
1. 页面布局：
   - 顶部汇总卡：已分析软件数、总占用、可清理（非必要缓存）总量。
   - 主列表：每行一个软件（图标可用首字母占位）、名称、发布者、总大小、**三段堆叠条**（本体=中性色，必要缓存=强调色，非必要缓存=警示色；必须同时配有文字/图例，不能只靠颜色区分）。
   - 排序（大小、可清理量、名称）、搜索、"仅显示可清理量 > 100MB"过滤。
2. 展开行显示明细：三类各自的目录列表（路径、大小、风险、理由、来源 rule/llm），可按大小排序；必要缓存带风险提示文案。
3. 每个软件和页面底部均有"清理非必要缓存"按钮，点击调用 `clean:preview`，弹出预览对话框（T13 实现执行，这里先完成预览对话框 UI 与 `clean:preview` 的对接，执行按钮在 T13 前 disabled）。
4. 数据加载：`apps:list` 一次性拉取摘要，明细按需 `apps:getBreakdown`。
5. 页面也要显示 AI 思考面板（复用 T10 组件）；分析中显示已完成的软件，未完成的显示骨架屏。
6. 空状态/错误状态完整；深浅色均检查对比度。

## 验收
- 组件测试：排序、过滤、展开、预览对话框打开与内容渲染。
- 三段条宽度比例单测（边界：某段为 0、总量为 0）。
- typecheck / test / lint 通过。
