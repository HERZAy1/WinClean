# T10 页面一：文件关系树 + 未归属面板

**前置**：T09

## 目标
用思维导图展示"软件 ↔ 文件 ↔ 注册表项"的关系；独立展示未归属文件及其 AI 简述。

## 要做
1. 主进程实现：`tree:getRoots`（所有 App 节点＋"Windows 系统"＋"未归属"三类，按大小降序）、`tree:getChildren`（懒加载；App 节点的子节点分组为：`安装目录`、`用户数据(AppData)`、`缓存/临时`、`注册表`、`其他`，每组再往下是目录/文件/注册表键）、`unowned:list`（分页，含已有 explain）。
2. 思维导图（React Flow + `d3-hierarchy` 或 `dagre` 布局）：
   - 中心为"这台电脑"，一级为软件（按大小取前 30，其余合并为"其他软件"，可展开）；
   - 点击节点展开子节点（调用 `tree:getChildren`），默认只显示一层；单次展开最多渲染 100 个子节点，超出显示"+N 项"节点，点击分页展开；
   - 节点显示名称、大小、归属置信度小徽标（来源 rule/llm）；注册表节点用不同图标；
   - 悬停显示完整路径与归属理由；支持缩放、拖动、小地图、"重置视图"；
   - 虚拟化：画布外节点不渲染（`onlyRenderVisibleElements`）。
3. 右侧详情抽屉：选中节点时显示路径、大小、归属理由、关联注册表项；提供"在资源管理器中显示"（`shell.showItemInFolder`）。
4. **未归属面板**（页面内标签切换"关系树 / 未归属"）：虚拟滚动列表，列：路径、大小、AI 简述（`summary`）、`kind` 徽标（残留/系统组件/临时缓存/用户数据/未知）、风险。未分析的条目显示"分析"按钮（调用 `unowned:explain`），支持"分析本页全部"。支持按 kind、大小排序与筛选。
5. 页面顶部：扫描/分析入口，并展示总进度条（扫描阶段）与"AI 思考"面板（展示 `LlmThinkingEvent`：当前批次、关注对象、流式文字的最后几行、tokens）。
6. 空状态与错误状态完整（未扫描、扫描中、无结果、LLM 未配置时引导去设置页）。

## 验收
- 用 10 万节点的合成数据库，初次展开与展开子节点的交互不卡顿（记录展开耗时）。
- 组件测试（Testing Library）：展开/收起、"+N 项"分页、未归属列表筛选与"分析"按钮触发。
- 浅色、深色截图各一张说明（或描述视觉检查结果）。
- typecheck / test / lint 通过。
